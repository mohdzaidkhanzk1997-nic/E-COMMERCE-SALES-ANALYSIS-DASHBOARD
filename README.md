📌 Project Overview

This project was created as a hands-on Excel data analytics project, inspired by an ecommerce dashboard development tutorial and independently implemented/adapted using Excel.

The dashboard provides an interactive view of ecommerce sales data and allows users to analyze important business metrics through dynamic charts, KPIs, and filters.

🎯 Objectives
Analyze overall ecommerce sales performance
Track key sales and business KPIs
Identify top-performing products and categories
Analyze sales trends over time
Understand customer purchasing patterns
Create an interactive and user-friendly dashboard
Convert raw data into actionable business insights

📈 Dashboard Features

The dashboard includes analysis of:

Total Sales
Total Orders
Total Quantity Sold
